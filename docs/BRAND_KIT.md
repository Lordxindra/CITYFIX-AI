# CityFix AI brand kit

- **Name:** CityFix AI
- **Descriptor:** The intelligence layer for better cities.
- **Tagline:** Report Less. Resolve More.
- **Personality:** Trustworthy, civic-minded, clear, calm and action-oriented.
- **Primary background:** Deep Obsidian Navy `#050912` (`--bg-elevated: #09101d`)
- **Surface:** Slate Command `#0b1322` (`--surface-strong: #0e1729`)
- **Primary accent:** Electric Cyan `#38bdf8` (`--accent-strong: #0284c7`)
- **Secondary accent:** Emerald `#10b981`
- **Attention / Severity:** Amber `#f59e0b` (High) · Crimson `#f43f5e` (Critical)
- **Typography:** Urbanist / Manrope for display headings; DM Sans for interface text; JetBrains Mono for IDs and telemetry.
- **Logo direction:** Minimal C-shaped cyan civic pin (`#38bdf8`) paired with a warm amber plus crosshair (`#fbbf24`) on `#0d172a` (`cityfix-logo.svg`); never use government seals or official municipal marks.
- **Voice:** Plain language, transparent about what is a prototype, never promise official resolution.
