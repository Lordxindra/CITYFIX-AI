Citizen workflow

From street observation to trackable reference in four steps.

Turning fragmented complaints into clear operational queues
  1. 01

    Upload photo & describe

    Attach an optional JPEG, PNG, or WebP photo (up to 5 MB) with instant preview and brief context.

  2. 02

    Pin location with consent

    Enter a Jaipur neighbourhood manually or share GPS coordinates strictly on explicit button press.

  3. 03

    Review AI triage

    Inspect suggested category, safety priority, visible evidence, and potential duplicate matches before submitting.

  4. 04

    Track status & audit trail

    Receive a unique reference ID (e.g. CF-1025) and follow status updates and admin audit events.

Trust, privacy & architecture

Engineered with clear boundaries and honest disclosures.

01

Server-side AI & secret isolation

Gemini API credentials remain strictly on the server or Supabase Edge Function—never shipped in browser scripts.

02

Row Level Security & private photo storage

Supabase schema enforces authenticated uploads, owner/admin-only signed photo URLs, and database-enforced admin status updates with an auditable issue_events trail.

03

Consent-first location & data minimisation

Device geolocation runs only when requested by the reporter. Residents can always type a neighbourhood name instead.

04

Clear demo vs. cloud separation

When cloud credentials or sign-in are inactive, CityFix runs in a clearly labelled local demo mode without pretending to dispatch municipal crews.
